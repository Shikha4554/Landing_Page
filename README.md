# Landing Page

A static landing page for a fictional travel agency, built with HTML and CSS as part of the CodSoft internship program.

## Tech Stack

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

## Features

- Header with navigation, contact info, and a "Request a Consult" call-to-action button
- Hero section ("Adventure Awaits") promoting travel packages
- Features section highlighting the business, support, and service offerings
- About Us section with a background image and company description
- Services section (User Experience, Hotels, Customer Services) with accompanying images
- Smooth-scroll navigation to in-page sections
- Footer with copyright notice

## Getting Started

Open `index.html` in a browser, or serve the folder locally:

```bash
npx serve
```
